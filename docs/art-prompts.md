# Barn artwork

Generated with the built-in imagegen tool, one transparent PNG per tier. All six final files are in `Textures/Things/Building/HerdBarn_0.png` through `HerdBarn_5.png`. The legacy texture is retained for existing small barns.

## Tier 0

Use case: stylized-concept. Asset type: one transparent PNG game building sprite for a RimWorld mod, tier 0. Subject: Neolithic timber-and-thatch livestock barn with simple open feeding yard. Single compact square 4x4 tile footprint viewed directly from above with slight south-facing roof/wall depth, orthographic colony-game building, north at top. Bold simple shapes, thick dark outlines, flat painted colors, few large readable details; no tiny textures. Entire building centered, occupies 85 percent of square canvas, clear transparent margin on every side. No text, labels, people, animals, terrain, background, shadows outside footprint or watermark. Transparent background. Match a hand-drawn top-down colony simulator sprite. Not isometric; square walls aligned with canvas axes.
